## 一句话

Admin 点一次「创建 Bot」→ **成功弹层挡住**：完整 `ymk_…` + 一键复制 + 「复制启动提示词」（内嵌安装 + API 根 + **本把钥匙** + whoami）；之后席页「复制入场链接/提示词」只带 `ymt_`，**不再让人再贴一把 ymk**。

## 两码不合并（产品冻结）

| 前缀 | 人话名 | 用途 | 出现场景 |
| --- | --- | --- | --- |
| **`ymk_`** | **身份钥匙** | Bot 是谁（Bearer） | **仅**创建成功弹层 / 首跑启动提示词（私贴）；列表只留末四 |
| **`ymt_`** | **入场码** | 进哪个队（join） | 入场链接、席页复制提示词、`/join`；**禁止**当身份用 |

**不做（P0）：** 把两码合成「一码通」。心智靠文案与分场景露出解决，不靠合并 token。

**现网痛点（须灭）：**

1. 「新建 API Key」成功后弹层关掉，明文只落在设置·接入 Tab 的 Alert——易漏看 → **像成功但没数据**。  
2. `POST /api-keys` 无 `member_id` 时依赖「工作区已有 is_bot」；无 Bot 成员则 400，却无「先创建 Bot」主路径。  
3. 席页/Join 向导仍二次要人贴 `ymk_`；与「复制即走」打架。  
4. UI 两处都叫「Key/码」，用户分不清。

| 做 | 不做 |

| 人话标签：「身份钥匙」vs「入场码」 | 教人改 mcp.json / 长 env 清单当主路径 |

## 契约

### F · 创建 Bot（Go + React）

```
POST /api/v1/workspaces/{ws}/bots
Body: { "display_name": "前端 Bot" }   // 名必填；其它字段实现可扩
→ 201 {
  "member": { id, display_name, is_bot: true, ... },
  "token": "ymk_…"   // 明文仅此一次，与 api-keys 创建同口径
}
```

- 事务内：`members` 插 `is_bot=1, role=bot, bot_enabled=1` + `api_keys` 插 hash；失败全滚。  
- 亦可实现为「现有 `POST …/api-keys` 在无 bot 时自动建成员」——**产品验收认结果：一次动作后手里有 member + 明文 ymk**，路由名以 Go 落地为准，债文以行为为准。  
- 旧「新建 API Key」（设置·接入）：**成功不得只关 Modal**；须同一套成功露出（可复用组件）。无 bot 成员时引导「去创建 Bot」或内联走 F 契约，禁只丢 400 英文味报错。

### 成功露出（FE 硬标准）

成功后 **Modal（推荐）或全宽 Alert 挡主按钮**：

1. 标题：「Bot 已创建 · 请复制身份钥匙（仅此一次）」  
2. 完整 `ymk_…` + **复制**（主按钮）  
3. 次按钮：「复制启动提示词」→ 剪贴板 = 首跑模板（见下）  
4. 关闭前二次确认若尚未复制（或关闭后仍可用本会话缓存的明文直到离开页；刷新后不可再取）  
5. 列表/名册刷新后该 Bot 可见；**禁止**成功 Toast 后名册仍空且无钥匙面

### 首跑启动提示词（可嵌 ymk_）

与 ONE_TAP `BuildBotPrompt` 同骨架，**额外**在身份段写入当次明文：

0. 安装（curl\|bash / go install）  
1. API 根  
2. **身份：`export YMBOT_API_KEY=ymk_…`（或 ymbot config 等价一行）** ← 仅此模板允许  
3. `ymbot whoami`  
4. （可选）若 Admin 同时签发了入场：再附 `ymt_` + `team join`；否则写「入队码由管理员另发入场链接」  
5. 警告置顶：**含密钥，勿发公开群 / 勿贴进可转发 Issue**

席页日常「复制 Bot 提示词」（ONE_TAP B2）**仍禁止**嵌 ymk_——只嵌 ymt_ + 安装 + join。

### 文案

| 场景 | 正确叫法 | 禁止 |
| --- | --- | --- |
| 创建成功 / 设置钥匙 | 身份钥匙（`ymk_`） | 「入场码」「邀请码」 |
| 席页复制 /join | 入场码 / 入场链接（`ymt_`） | 「API Key」「Bot Key」当主名 |
| Join 向导人类旁路 | 可保留贴钥匙；主 CTA 指向「用已复制的启动提示词」 | 强迫 CLI 用户再贴一次 |
