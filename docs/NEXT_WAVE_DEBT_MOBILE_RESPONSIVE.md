## P0 目标态（本刀）

窄屏（≤768 / Ant `lg` 以下）主路径：

1. **登录门**：卡宽已 400+`max-width:100%`；确认手机竖屏无横溢、可登录/注册。  
2. **壳层**：侧栏在窄屏默认收起/抽屉化，汉堡可开；顶栏不挤爆、不挡主 CTA。  
3. **看板**：列可横滑；卡片可点开；拖拽不挡点按打开（触控冲突软处理）。  
4. **Issue 详情**：沿现 639 窄轨——主栏+属性可上下读；关闭/保存可点。  
5. **禁横溢**：主壳 `overflow-x` 可控；无整页被固定 Sider 挤出视口「打不开」。

## 非目标（本刀）

- 不做独立 `mobile/` 包、不另端口、不 PWA/App Store。  
- 不重做 Wiki/工时/超管台完美移动（可列 P1 债）。  
- 不改 `/api/v1` 契约；不碰 Soft 三件。  
- 不要求像素级原生 App 手感。
