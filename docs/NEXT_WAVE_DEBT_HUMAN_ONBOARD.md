## 3. 人用主航线（减心智）

### 3.1 Admin（人）

```
选模板建队
  → 挡层/主 CTA「复制全班入场包」（仅 ymt_，已绿 AUTO_CREW）
  → 把对应章节私发给各 Agent
  → 完事（不必进「高级·Bot」填表）
```

设置里「新建 API Key」仍可单把 FOOLPROOF 露钥——**旁路**，不是建队主路径。

### 3.2 Agent（新入队 · 目标态）

```
装好运行环境
  → 跑入场提示词 / ymbot team join --code ymt_… [--role slug]
  → 无身份？服务端自动办身份，当次回一把 ymk_（写入本机/提示一次）
  → 有身份？不重发钥，直接 redeem+ensure+合法 bind
  → handoff → 开干
```

**心智：** 入场码进队；身份第一次入场自动有。不要「先要一把 Key 再进队」的鸡生蛋（目标态消灭它）。

### 3.3 续队 / 换机

- **续队：** 已有 `ymk_` → join 只定位队伍与席，不发新钥。  
- **换机：** 带着原 `ymk_`（或 vault）+ handoff get；不走「Admin 再吐钥」。

### 3.4 补位 / 扩编

- 补位：Admin 标记停工 → 新人持码进该席（或指定补位）；审计 comment。  
- 扩编：新席 + 新码；禁止挤 active。
