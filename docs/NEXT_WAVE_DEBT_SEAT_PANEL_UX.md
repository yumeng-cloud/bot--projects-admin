# Bot 席位实态 + 入场码展示 · SEAT_PANEL_UX

> 2026-10-25 08:48 Asia/Shanghai · 产品体验主持拍板  
> **承接：** 用户截图 Bot 席位（研学平台）：多数席「可补位」像没绑上（他以为「你们都加入了」）；下方「已签发入场码」长列表+吊销堆叠丑乱。  
> **强令：** 禁再口头说已加入却席上空；入场码勿垃圾墙。合议→修→QA 自测再交。不问用户。  
> **并行：** SETTINGS_EDIT / MOBILE 仍开；本刀 **P0 体验**。Soft 三件仍冻（禁解冻通码静默补）。

## 合议结论（产品锁死）

### 1）席位占用真相（人话三态）

| 实态 | 页上人话（锁死） | 判定 |
| --- | --- | --- |
| 已绑活跃 | **在席 · {Bot 显示名}** | `active` / 有 `bound_member_id`\|claim |
| 从未占用 | **空闲**（从未占用） | `empty`/`open`/无绑且非 stopped/left |
| 曾绑已清 | **停工可补**（禁把「可补位」当空态） | `stopped`\|`left`\|`departed` |

**禁混：**

- 工作区有 Bot 成员 / 有 API Key / 人类后台「以为加入」≠ 本队席占用。  
- 页上 **只认本队 roster**；不得把「Grok 会话里说加入了」画成占用中。

**补一条诚实条（若有数据）：** 本工作区存在 Bot 成员却 **未占本队任一席** → 页顶/旁路人话：  
「本工作区有 N 个 Bot 尚未占本队席」+ 引导（加入班底 / 复制补位码 / 指派）。  
**禁**把他们画进「占用中」。

**任用纠偏：** 记忆+Go 查清研学平台各角色：真没进席 → 按任用补绑路径（补位码/force Admin，**不**解冻 Soft V2 静默补）；进了别队 → 文案点明「在队 X」或引导迁席；展示错 → 修 FE/API。

### 2）已签发入场码（禁裸末四刷屏）

| 拍死 | 不做 |
| --- | --- |
| **默认折叠摘要**：`有效 N · 已吊销 M`（或「暂无有效入场码」） | 一进来整墙末四 |
| **按席/role_hint 分组**；无 hint →「未指定席」 | 平铺无结构 |
| **默认只展开有效**；已吊销进二级「已吊销」折叠 | 有效与吊销混排刷屏 |
| 行内仍：末四 + 状态 Tag + 吊销（有效行） | 展示明文 ymt_ |
| 无任何码 → **整卡隐藏**（或极简「暂无已签发」一行） | 空卡占版 |

视觉尺子：跟设置密度；折叠标题一行、组间距紧；热区≥44（MOBILE 并行不挡）。


## 视觉尺子（总监 · 合议锁 · 2026-10-25）

| 项 | 锁 |
| --- | --- |
| 入场码默认 | **折叠摘要**：`已签发 N · 有效 M`（点开再展） |
| 分组 | **按席 / role_hint**；无 hint →「未指定席」 |
| 同组展示 | 默认同组只展 **1～2** 条末四，其余「还有 k 条」展开 |
| 码种 | **ymw_ / ymt_ 分块**（勿混一列） |
| 行高 | **36–40px** |
| 吊销 | 二级折叠「已吊销」；禁与有效混排刷屏 |
| 禁 | 裸末四整墙；明文 ymt_ 列表 |


## 密度尺子（审图锁 · 跟设置 bots.css · 2026-10-25）

| 项 | 锁 |
| --- | --- |
| 节奏 | **8px** |
| 区段间隙 | `--acb-bots-section-gap: 12px` |
| 卡垫 | `10px 12px` |
| 席格 | gap `8px`、min `260px` |
| 桌面行高 | `--acb-bots-row-h: 36`（表/操作行；入场码行 **36–40**） |
| 折叠头 | 一行 `8×12`、字 **13** |
| 触控 | 窄屏热区 **≥44**；桌面不降到 **&lt;36** |
| 箱截 | 席三态一帧 + 入场码折叠/展开分组一帧 |
| 禁 | 另皮、挤叠糊字、Landing、末四墙、空卡死白 |
