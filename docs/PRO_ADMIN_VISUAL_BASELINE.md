## 0. 一句话

设置与超管台要像「敢演示的中文专业后台」：分区清楚、表行可读、少数据时表面随高接地；**禁**单页 Form 栅格挤满，**也禁**下半屏空罐死白。

## 1. 共用节奏（跟板 / Wiki 同一套）

| 项 | 硬值 / 规则 |
| --- | --- |
| 页底灰 | 浅色 `#F2F4F8`（深色跟现网 token）；侧栏通栏贴视口底 |
| 主表面 | 白/深表面；**内容少时 hug 内容高**，页底灰露出（V-CLOSE 刀 A 已验）；**禁**空 `stretch` 造死白 |
| 页眉 | 标题 **20/600** + 副文 **13** secondary；**主操作同一排右对齐**（飞书后台顶条节奏） |
| 分区距 | 区块之间 **24–32**；区内表行高 **40–44**（可读优先；`<36` 挤叠 FAIL，`>56` 疏到空海 FAIL） |
| 芯片 | 内边距 **≥8**、间距 **≥8**；角色用人话「管理员 / 成员 / 机器人」 |
| 表结构 | **顶操作条 + 表**；空态 = 短说明 + **单一主 CTA**，禁半屏插画 |
| 文案 | 禁露 `admin` / `member` / `is_bot` / raw slug / UUID |

深色主题下结构规则不变；只换 token，不另起欧美大留白皮肤。

## 2. 设置页（承接 A1 + F）

### 2.1 信息架构（A1）

顶部分区须清晰，与侧栏「设置」语义一致。推荐 **Tabs**（或左锚二级）：

| 区 | 内容 | 说明 |
| --- | --- | --- |
| **工作区** | 改名 / slug | 本区独立；勿塞进成员 Tab |
| **成员** | 邀请 + 成员表 | 邀请区与表**分块**，禁两坨 Form 糊一起 |
| **标签** | 标签表 + 顶操作 | — |
| **接入** | API Key · Webhook | 可同 Tab 内二级分段；禁四个平级 Tab 把「接入」拆得过碎导致顶栏拥挤 |

**Bot** 仍走侧栏独立入口；成员表下允许一行脚注指向 Bot，**禁止**把 Bot 席位配置塞进设置 Form 栅格。

现网若仍是「成员 / 标签 / API Key / Webhook」四 Tab：A 落地时收敛为上表四区（API Key+Webhook →「接入」），并**补「工作区」区**。

### 2.2 工作区密度与文案（F1）

- 短说明 **≤1 行** + 字段；禁大段灰字说明书。
- **slug** 仅管理员可见；旁注一句人话：「用于 URL」。
- 保存为页眉主操作或字段区末行次按钮，勿漂浮大 Card。

### 2.3 成员 / 标签 / 接入（F2 · 对齐 D1 视觉）

- 成员：**上**邀请（或签发 `ymw_` 入口），**下**表；中弱分隔线。
- 标签 / 接入：表 + 顶「新建」；空态标题中文（如「还没有 API Key」），**禁**用英文 key 名当标题。
- 表首屏：在 1280×800 箱截下，标题+Tabs+表头后至少可见 **≥3 行**（或空态功能块）；内容区下半 **无功能空 >50% → FAIL**。

## 3. 超管台（承接 A2）

### 3.1 壳

```
┌ 标题「平台管理」 + 副文 + 主操作（新建工作区） 一排 ─────────────┐
│ Tabs 或对等两区：工作区 | 用户                                      │
│ 表区 hug / 短列表策略同 §1；禁漂浮卡片悬空半屏                      │
└────────────────────────────────────────────────────────────────────┘
```

- **工作区 / 用户两区视觉权重对等**（禁一侧大空白一侧挤表）。
- 顶栏禁止只有标题、主按钮掉到表外很远。

### 3.2 表密度

- 行高 **40–44**；状态用芯片（启用/停用），不堆开关墙。
- 工作区：名称搜索 + 状态筛选入口预留（能力见债 C4）。
- 用户：搜索防抖；所属工作区芯片可读；空搜索有短提示。

## 5. 打回红线（对齐 G1）

任一即 **FAIL / 打回**：

1. 中文叠字、芯片糊团、行高 `<36`  
2. 下半屏无功能死白 / 空罐 stretch（已关的 ST-V1 不得回潮）  
3. 露技术文案（`admin` / `member` / `is_bot` / UUID / 生 slug）  
4. 另起欧美大留白皮肤，或为「塞满」而挤叠  

放行路径：React 箱截 → **UI视觉·审图自审** → **视觉总监复核** → 产品勾。
