## 0. 一句话

**管理面**（库列表/设置）与 **写作面**（目录+舞台）视觉分离；目录像书脊，舞台像文档：大标题 → 单行属性 → 正文。通栏满高；中文可读优先。

## 3. Wiki 顶条（写作面常驻）

- 左：当前库名（可点 ▾ 切换）+ 文案「知识库」气质，**不是**隐身 Select。
- 右：**管理**（或齿轮）→ 打开管理面；勿在顶条堆建页/删页。
- 字号：库名 **15/600**；次操作 **13/400** secondary。
- 与 App 顶栏分层清晰：App 顶管工作区/用户；Wiki 顶管知识库。

---

## 4. 目录栏（书的目录）

### 4.1 结构自上而下
1. 「Wiki」标题行 + 刷新 / +（+ 仅「在当前库新建页」，不建库）
2. 当前库胶囊（可省略若顶条已强展示库名）
3. 搜索页（高 32–36，圆角 6）
4. 「目录」标签 + 「+ 新建页」
5. 树

### 4.2 树行（不过关即打回）
- **同一行**：`[图标 16] [标题 14/500 ellipsis] … [⋯ hover 才显]`  
  **禁止**图标与标题拆成两行；禁止空图标鬼行。
- 选中：浅强调底（与全局选中同色相，透明度约 12–16%），圆角 **8**。
- 缩进：每级 **16**。
- ⋯ 菜单：新建子页 / 重命名(P2.1) / 删除 —— 文案人话，不露 id。

### 4.3 空库
短说明 + 主按钮「新建第一页」；插画可选，高度克制，**不要**半屏插画造死白。

## 5. 页面舞台（文档感）

自上而下节奏（固定，勿乱插工具条打断标题）：

| 层 | 规格 |
|----|------|
| 面包屑 | 13 / secondary；库名 / 祖先… |
| 工具微区 | 同行右对齐：保存微文案（「已保存 · ⌘S」）· **编辑** · ⋯ |
| **大标题** | **30–32 / 700**，行高 1.25；阅读态纯展示，编辑态可变输入 |
| 更新时间 | 12–13 / secondary；紧贴标题下 **8** |
| **属性轨** | **单行**芯片；`padding ≥8`；芯片间距 **≥8**（推荐 12）；过多则「+N」或「展开」 |
| 正文 | 16 / 400，行高 **1.75**；阅读渲染 / 编辑 ByteMD；与属性轨间距 **24** |

### 5.1 属性芯片
- 未关联：虚线边 + 「项目 未关联」类文案 —— 可读，**禁止**糊成一团。
- 已关联：实线 + 名称截断。
- 点击出选择器；**禁止**在舞台再开三字段建页 Modal。

### 5.2 编辑态
- 显式「编辑」进入（定稿，防误触）。
- 无紫「完成」；退出编辑 = 再点或自动保存后保持编辑均可，但主色不要抢标题。
- 工具条（ByteMD）贴正文顶，弱化，高度 ≤40。

### 5.3 砍掉的视觉
- 写作区建页大 Modal  
- 属性与目录挤同一窄列  
- 标题下密密麻麻 Form 栅格  
- 下半屏无功能白海同时顶区控件挤扁  

短文页下方留白 = **阅读栏呼吸**，允许；判定 FAIL 的是「壳不到底 + 控件挤」或「真有数据却空态」。

## 6. 管理面（与写作面分离）

| 形态 | 规格 |
|------|------|
| 入口 | 顶条「管理」 |
| 容器 | 右侧抽屉宽 **400–440**，或子路由整页；灰遮罩 |
| 列表 | 表或卡片：库名、页数、更新时间、⋯；主按钮「新建知识库」 |
| 单库设置（P2 最小） | 名称、描述；成员权限无 API 则灰置「即将支持」，**禁止假做** |
| 气质 | 后台管理密度可略高于写作面，但仍守手册：不叠字、不通栏偷懒 |

建库、改名只在管理面完成；写完回写作面。
