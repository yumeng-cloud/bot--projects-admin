## 0. 一句话

把 Wiki 从「侧栏树 + 中间写字的后台页」改成国内用户认得的 **知识库工作台**：库可管、目录像书、正文像飞书文档、属性像页眉字段——管理与写作分面。

## 1. 对标原则（必须写进实现注释）

| 原则 | 飞书/语雀/Notion 中文习惯 | 本产品落地 |
|------|---------------------------|------------|
| 有序密度 | 中文方块字要密而可读，不崇尚欧美大白海 | 跟 `CN_VISUAL_QA_PLAYBOOK`：树≥280（默认 300–320）、行高≥36、芯片间距≥8 |
| 通栏满高 | 侧栏色底贴视口底 | `100dvh` 链：App → Wiki shell → 目录/舞台 |
| 库 → 目录 → 页 | 先有「库/知识库」再写页 | Space 用户文案统一叫 **知识库** |
| 写作 vs 管理 | 设置进独立入口 | 写作面零建库 Modal；管理进抽屉/子页 |
| 编辑即存 | 无「提交/完成」主 CTA | 自动保存 + ⌘S 微文案；删除进 ⋯ |
| 禁老 demo | 无 UUID、无三字段建页弹窗、无裸 Select 墙 | 继承 P0 流程胜利，推倒 P1 缝补壳重做布局 |

## 2. 信息架构

```
工作区
 └ Wiki
    ├ 知识库（Space）列表 / 切换 / 管理     ← 管理面
    └ 知识库工作台（当前 Space）           ← 写作面
         ├ 左：目录树（搜索、新建、⋯）
         └ 右：页面舞台（标题、属性轨、正文）
```

| 对象 | 用户叫法 | 说明 |
|------|----------|------|
| Space | 知识库 | 名称、描述；P0 要能新建/切换/改名描述 |
| Page | 页面 | 标题 + Markdown 正文 + 可选关联 |
| 属性 | 页面属性 | 项目 / Issue / 父级 —— 芯片，非表单 |

**两条路径**  
1. 写作（主）：进 Wiki → 当前库 → 点目录 → 读/写。  
2. 管理（次）：顶条「管理」/齿轮 → 库列表与库设置抽屉。

## 3. 布局分区

```
┌ AppNav │ 顶条：当前知识库 ▾ · 管理 ·（可选全局搜索后置）─────────────┐
│        ├─ 目录 300–320px ─┬─ 页面舞台（阅读栏 max 720–800）─────────┤
│        │ 搜索 / 树 / +新建 │ 面包屑 · 保存态 · 编辑 · ⋯              │
│        │ 行高≥36 · ⋯菜单  │ 大标题                                   │
│        │                  │ 属性轨（单行芯片，可展开）                │
│        │                  │ 正文：阅读=渲染；编辑=ByteMD              │
│        └──────────────────┴─────────────────────────────────────────┘
└ 整壳 100dvh，目录灰底与舞台白底均贴视口底 ────────────────────────────┘
```

### 3.1 左树（目录）
- 宽默认 **300–320**（底线 280）
- 结构：库内搜索 →「目录」+「新建页」同行 → 树
- 节点：图标 + 标题 ellipsis + hover/选中 ⋯（新建子页 / 删除；重命名可 P0.1）
- 当前页高亮；父子缩进清楚
- **滚动**：仅目录列内部滚动，不带动整页 App 乱跳

### 3.2 主文（舞台）
- 阅读栏居中或左对齐留呼吸，**禁止**标题漂在大白海中央无栏宽
- 字号层级：标题 ≫ 正文 ≫ 属性/元信息
- **滚动**：舞台列独立滚动；顶栏（面包屑/保存/编辑）可 sticky 在舞台顶

### 3.3 属性轨
- 标题下 **单行芯片**：项目 · Issue · 父级
- 默认不露大 Select；点击芯片 → 弹出搜索选择（沿用芯片交互）
- 属性是辅，不与正文抢第一视线

---

## 4. 密度与滚动（硬约束）

1. 目录与舞台 **分栏各自 overflow**，禁止整页只有中间一块短面板。  
2. 通栏满高：无下半屏死白。  
3. 中文不叠字、不糊成团；芯片 gap≥8、padding≥6×10。  
4. 一屏内能同时看到：当前树上下文 + 标题 + 正文开头。

---

## 5. 空态

| 场景 | 表现 |
|------|------|
| 无任何知识库 | 居中短文案 +「新建知识库」主按钮（进管理流） |
| 有库无页面 | 目录空态 + 舞台「新建第一页」 |
| 有页未选中 | 舞台提示选目录或新建（勿与已有树矛盾） |
| 搜索无命中 | 目录内「无匹配页面」 |

空态文案人话、短；禁技术词。

---

## 6. 编辑态

- 默认 **阅读态**；点「编辑」进编辑态（显式，防误触）
- 编辑态：标题 inline + ByteMD；工具条克制（对标 Issue 描述）
- 保存：防抖自动 + ⌘S；文案「保存中… / 已保存 / 编辑中 · ⌘S」
- **禁止**「完成」紫主按钮
- 退出编辑 / 删除 / 移动 → ⋯ 菜单
- 建页：目录「新建」或「新建子页」→ **立即草稿**「无标题」进舞台编辑（无三字段 Modal）

---

## 7. 管理面（P0 最小）

- 入口：顶条「管理」
- 库列表：名称、更新时间、⋯  
- 新建知识库：名称 + 可选描述（抽屉或独立轻页，**非**写作 Modal）
- 库设置最小：改名、描述  
- 成员/权限：标 P0.1（无 API 则入口灰置「即将支持」，禁假做）

---

## 8. 非本轮

块编辑器、实时协同、评论、拖拽排序、跨库移动、完整 ACL（→ P0.1/P1）。
