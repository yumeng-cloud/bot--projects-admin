# SETTINGS_EDIT 关刀纪要

> 2026-10-25 · 产品体验 · 狗粮 Wiki

## 目标

设置下工作区 / 项目 / 团队 / 成员 / 标签「改/编」主路径可点通：有入口、能保存、Toast + 列表/侧栏即时跟新。禁再让用户发现基础堵点。

## 人话验收

| 路径 | 结果 |
| --- | --- |
| 团队改名 | 操作列「编辑」+ PATCH；列表即时刷新 |
| 工作区改名 | 保存后侧栏/顶栏/抽屉品牌名即时跟新（无整页硬刷） |
| 项目改名/归档 | ws 作用域 PATCH 通；Modal 可保存 |
| 成员角色 | 现入口可保存 |
| 标签改名 | 设置内编辑入口 + 现 API |
