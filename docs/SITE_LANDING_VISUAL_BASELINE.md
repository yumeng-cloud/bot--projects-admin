## 0. 一句话

登录前默认页是**产品说明书式一页门**——跟看板同一套肤讲清「人与 Agent 一支队」；**不是** SaaS 暗黑营销站，也**不是**登录卡扩成 Landing。

## 1. 气质与对标

| 项 | 锁 |
| --- | --- |
| 气质 | 安静、敢演示的中文正式产品介绍；有序密度 |
| 对标 | 飞书 / Notion 中文**产品介绍页的克制版**（短、可读、少块） |
| 禁对标 | Syfo / CrewX / Wolf 暗黑 hero、插画墙、英文 slogan 堆、渐变光晕 |
| 与登录门 | 同品牌、同 token、同字重节奏；官网讲故事，登录仍是冷灰+白卡 400 |

## 2. 路由口径（视觉验得到）

| 态 | 页 |
| --- | --- |
| 未登录打开 `/` | **官网落地**（本基线） |
| CTA「登录 / 注册 / 进入工作区」 | 进现有 `LoginPage`（LOGIN_REFRESH 已放行） |
| 已登录 | **后台**（Home / 看板等），勿把官网塞进鉴权后壳 |

打回：未登录仍直落登录卡且无官网；或登录后仍困在营销页。

## 3. 叙事硬门（文案产品锁；视觉验出现）

必须在首屏或紧随首屏的 **≤3 块**里同时看见：

1. **人与 Agent 一支队**（同场协作，不是「多开聊天窗」）
2. **换机 = 分布式**：不同电脑认领不同角色干活，干完**统一调度**（禁写成「换电脑续会话 / handoff 话术」）
3. **席位班底 · 按需入场 K · 决策/审查强模型 · 写码轻量**（可作第三块或副句；本刀不实现档位配置 UI）

主标题品牌名锁：**育蒙协作看板**。禁 Linear / laner / Grok Bot / 英文主 slogan。

## 4. 信息架构（硬上限）

```
┌ 顶栏：品牌左 · 登录/注册右 ─────────────────────────────────┐
│ Hero：主标 ≤2 行 + 副标 1 句 + 主 CTA（进入/登录）            │
│ 价值 ≤3 块：一支队 | 分布式换机 | 席位·按需K·模型档           │
│ 底栏极简（产品名 + 工作区入口）                               │
└──────────────────────────────────────────────────────────────┘
```

| 项 | 锁 |
| --- | --- |
| Section | **≤4**（顶栏不计）：Hero + ≤3 价值 + 可选极简底；**禁** 5+ 长滚卖点墙 |
| 价值块 | 每块标题 **≤12 字** + 正文 **≤2 行**；禁 feature 说明书 |
| 插画/示意 | **≤1** 个产品示意（席位/多机简图即可）；禁 AI 炫光、插画墙 |
| 导航锚点 | 可有，但禁「04 · 精髓」编号营销腔 |

## 5. 视觉 token（跟 app，禁另皮）

| 项 | 锁 |
| --- | --- |
| 画布 | 浅色 `--acb-bg-layout`（`#F2F4F8`）；深色跟现网 token |
| 表面 | `--acb-bg-container`；卡片/块圆角 **8**（跟登录卡） |
| 主色 | **`#5E6AD2`**（现 `--acb-primary`）；禁 `#5b8cff`、青绿 accent、径向 glow |
| 字 | 系统中文字体栈（跟 app）；**禁** Google Fonts / Noto CDN 外挂 |
| Hero 主标 | **28–36 / 600**；副标 **14–15** tertiary |
| 区块距 | **32–48**；区内节奏 **8/12** |
| 按钮 | Ant 主按钮节奏；**禁** 大胶囊 999px 堆、双主 CTA 抢戏 |
| 留白 | 有序；**禁**下半屏死白，也**禁**暗海无功能空 |
