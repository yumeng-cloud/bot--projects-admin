### 4.2 资产落盘与用法

| 项 | 锁 |
| --- | --- |
| 目录 | `frontend/src/pages/Landing/assets/`（随 FE 发版） |
| 格式 | **WebP 优先**，PNG 可；单张源文件 ≤ 400KB 为目标（可压缩） |
| 用法 | `<img>` 或 CSS `background-image` 引**静态文件**；圆角 8–12；细边或轻阴影 `0 8px 24px rgba(0,0,0,.06)` |
| 禁 | 运行时 CSS 拼假看板当主图；外链图床；未压缩 4K 原图塞仓 |

### 4.3 整页设计（非只贴图）

- 主宽 **1040–1120**；区距 **48–64**  
- **≥3 处**左右图文交替（一文一真图）  
- Hero 真图占比 ≥ 首屏右半  
- 步骤区可保留 1–4 数字，但下方/旁侧须 **IMG-Flow** 真图  
- 旧 `mocks.tsx` / `landing-mocks.css`：**须下线或降为非主视觉**（不得再当 SL-V 交帧主证据）
