## 根因（产品初判）

1. **团队：** FE `SettingsTeamsPanel` 操作列无「编辑/改名」；Go **无** `PATCH/PUT …/teams/{id}` 改名 API（仅 Create/Get/List + 席/码）。→ 与用户截图一致，**P0**。  
2. **项目：** 已有 `EditProjectModal` + `patchProject`——须 QA 点通，坏则修。  
3. **工作区：** 设置·工作区 Tab + `patchWorkspace`——须点通。  
4. **成员：** 角色变更/移除——须点通（移除级联已 UNBIND 关）。  
5. **标签等：** 设置内凡「改/编」入口一并纳入矩阵，缺则补、坏则修。


## 扩拍（2026-10-25 · 产品锁死）

1. **项目写路径**：FE `patchProject` → `PATCH /workspaces/{ws}/projects/{id}`；Router 仅挂顶层 `PATCH /projects/{id}` → **易 404**。  
   **拍死：Go 补挂 ws 作用域**（`ws.Patch("/projects/{projectID}", projH.Patch)`，顶层保留兼容）；**不改 FE path**。归档/改名同路。  
2. **标签**：BE 已有 PATCH；设置页无编辑入口 → **本刀一并做**（S-R5：入口+对接现 API）。  
3. **团队**：仍 S-G1 + S-R1（用户怒点）。

## 目标态

设置下 **工作区 / 项目 / 团队 / 成员 / 标签** 主路径：

- 每类实体有明确「编辑/改名」入口（人话中文；非藏高级 Form）。  
- 保存成功 Toast + 列表即时刷新；失败人话，禁白屏/无响应按钮。  
- 团队：操作列含 **编辑**（改名±简介若有字段）；Admin 可改。  
- Go：`PATCH /api/v1/workspaces/{ws}/teams/{teamID}`（最少 `name`）；单测。

## 非目标

- 不重做设置 IA；不另起移动设置页（跟 MOBILE 壳即可）。  
- 不删团队/毁档（可另票）；不碰 Soft 三件。  
- 不扩 OAuth。
