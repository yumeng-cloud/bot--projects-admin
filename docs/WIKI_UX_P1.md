## 对标（必须看起来像）

- **Notion / Outline / Linear Docs / GitBook**：左树稳、正文阅读宽、属性芯片化、自动保存无「完成」主 CTA。  
- **禁止**：Ant Form 栅格感、大块空白漂浮、Select 当主视觉、顶栏图标汤、像 2018 admin template。

## 截图里必须死掉的问题

1. 主区大片空白，标题/正文悬在中间像未做完的稿  
2. 目录侧栏过窄、像塞进去的抽屉，不是「书的目录」  
3. 「关联项目 / 关联 Issue」用裸 Select 横排在标题下——工单味  
4. 「编辑 | 预览 | 图标…」工具条廉价  
5. 右上「完成」紫胶囊 + 删除像后台后台按钮组（已有 ⌘S / 自动保存）  
6. 阅读密度与字号层级不对（Inter 冷灰已有，Wiki 没用上）

## 定稿布局

```
┌ App Sider │ Wiki 目录树（240–280） │ 文档舞台（max-width ~720–760 居中或左对齐有呼吸） ┐
│           │ 搜索 + 树 + ⋯菜单      │ 顶：面包屑/空间 · 保存态微文案（非大按钮）        │
│           │                        │ 大标题 inline                                      │
│           │                        │ Property 芯片轨（项目·Issue·父级）可点弹出         │
│           │                        │ 正文：阅读=渲染；编辑=ByteMD 满高，工具条克制      │
└───────────┴────────────────────────┴────────────────────────────────────────────────────┘
```

## 验收（产品勾选）

| ID | 标准 |
|----|------|
| **P1-1** | 同分辨率下不再出现「标题漂在白海中央」；正文区有明确阅读栏宽与上下节奏 |
| **P1-2** | 目录树宽度 **≥280**（用户红框：240 过挤），行高/hover/选中态对标 Linear 侧栏；空树有像样空态 |
| **P1-3** | 关联项目/Issue/父级改为 **Property 芯片**（或右侧紧凑轨），默认不露大 Select 行 |
| **P1-4** | 去掉「完成」作主按钮；保存态仅「已保存 / 保存中 / ⌘S」微文案；删除进 ⋯ 或危险次要 |
| **P1-5** | 编辑/预览切换与 MD 工具条克制（对标 Issue 抽屉 ByteMD），非图标汤 |
| **P1-6** | 配色/字号继承 UI_CLEAN（画布 #F7F8FA、侧栏 #F2F4F8、Inter）；Wiki 不另起一套老紫 |
| **P1-7** | 产品本机 `5174` 硬刷后截图验收；看起来像 2024 文档产品，不像 admin demo |
