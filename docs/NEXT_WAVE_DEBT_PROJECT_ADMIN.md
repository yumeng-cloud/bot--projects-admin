# 项目 + 团队全闭环（PROJECT_ADMIN · 含 TEAM_ADMIN）

> 2026-10-24 22:15 Asia/Shanghai · 产品体验  
> **用户定调（总指挥转·怒）：** ①几乎只有「示例项目」、看不见管理/创建；②团队「暂无团队」死胡同。  
> **要：** 设置/顶栏 **项目** = 列表+新建+改名/归档；**团队** = 常驻管理面（列表/新建/切换/成员入口）；与空态 B1 / 快捷建队 **同一 API**；禁再只有示例、禁死胡同。  
> **承接：** `PRO_ADMIN` B1；`CreateTeamQuickModal`；BE projects/teams **大体已齐**，本刀主 FE。

## 一句话

用户随时能在顶栏或设置里管理 **项目** 与 **团队**（列表/新建/切换；项目改名归档；团队进成员/Bot 席）；创建与空态/快捷 Modal 同一套 API，不再靠示例 seed，也不困在「暂无团队」。

## 现网

| 层 | 现状 |
| --- | --- |
| **BE** | `GET/POST …/projects`；`GET/PATCH …/projects/{id}`（`name`/`description`/`archive`）；`?include_archived=1` |
| **BE · seed** | `e162e41`：默认不灌演示；`SEED_SAMPLE_DATA=1` 才灌样例；`seed_meta` 防重入；现网 `AUTO_SEED=0` |
| **FE · 项目** | 顶栏 Select 切项目；B1 空态创建 Modal 已有；**无**项目列表管理面；设置无「项目」区 |

| **痛点** | 有示例则误以为不能建；无示例/无队则死胡同；管理入口失踪 |

## 含 / 不含

| 做 | 不做 |
| --- | --- |
| 设置「项目」Tab（或顶栏「管理项目」）：表=名称/前缀/状态 + 新建/改名/归档/恢复 | 跨 WS 搬项目、项目级细权大重构 |
| 顶栏项目选择器：列表真实、底部「+ 新建项目」「管理项目…」 | 删项目物理删除（归档即可） |
| 新建 = 复用 `CreateProjectModal` / 同 `createProject` API（与 B1 一套） | 另造第二套创建 API |
| 改名/简介/归档接 `patchProject`；归档默认不进顶栏池 | 改 `key_prefix` 大迁移（可选后置） |
| 箱截：列表有 ≥2 项目、新建、归档后顶栏消失 | 重做看板 IA |
| 设置「团队」Tab + 顶栏队选择器常驻管理（列表/新建/切换/成员·Bot 入口） | 未分队大入口、跨队搬家、T7 升版 |
| 0 队：顶栏/设置可建队，禁只显示「暂无团队」无主 CTA | 重做席位 claim |
