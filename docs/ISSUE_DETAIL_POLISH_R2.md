## 0. 给总指挥

**原则**：少按钮、少边框、少「暂无」墙；属性即时保存；评论 ⌘Enter；空态只留一句占位。

**验收**：下表 R1–R6；产品体验 5174 截图勾，拒假勾。

**指派**：UI 视觉（CSS/token 主责）｜React（顶栏保存策略、评论发送、空态文案结构）。

---

## 1. 糙点 → 验收

| ID | 现网问题（相对 Linear） | 标准 | 指派 | 状态 |
|----|-------------------------|------|------|------|
| **R1** | 顶栏「取消」+ 实心蓝「保存」像后台 Form | 属性已即时 PATCH 的，**去掉实心保存主按钮**；关闭用抽屉 X / Esc。若标题描述仍需显式保存：改为顶栏幽灵「保存」或 blur 自动存，取消并入关闭（未保存提示可留） | React + UI | [x] |
| **R2** | 评论区大灰输入框 + 显眼「发送评论」 | Composer 更轻：边框/底更淡；主路径 **⌘/Ctrl+Enter**；「发送」改为文字链或弱按钮，默认不抢主色实心 | React + UI | [x] |
| **R3** | 「附件」标题 +「添加附件」+「暂无附件」三件套吵 | 空态一行：纸夹 +「添加附件…」；有文件再出列表。去掉重复「暂无附件」墙 | React + UI | [x] |

3. **R3**：`IssueAttachmentSection` 空态合并。  
4. **R4–R6**：`issue-detail.css` + token；Select `suffixIcon` 可用 CSS 降 opacity。
