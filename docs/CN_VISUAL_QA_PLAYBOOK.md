# 中文协作产品 · 审图审美手册（育蒙 AI 协作看板）

> 给「UI 视觉 / 审图」：对标飞书文档 / Notion 中文 / Linear，**不是**照搬欧美大留白，也**不是**电商超密堆砌。

## 一句话

中文方块字信息密度高 → **宁可内容稍密，也禁止挤到叠字、芯片糊成一团**；留白要有功能（分组、阅读栏、节奏），禁止下半屏死白 + 控件区挤扁。

## 硬规则（不过关即打回）

1. **可读优先**：中文标题/目录项不截断、不叠字；树宽 ≥280，行高 ≥36，芯片内边距 ≥8、芯片间距 ≥8。
2. **通栏满高**：侧栏灰底必须落到视口底；禁止「短面板悬在上半屏」。
3. **有序密度**：一屏能看清主任务；空态只在真无数据时出现，且不与已有目录矛盾。
4. **禁技术文案**：不露 slug / raw UUID / `members.role` / `is_bot`。
5. **禁欧美空白崇拜**：大片无功能白海 = FAIL；同时禁「为了塞满而挤」。
6. **对标**：板/列表/排期已 PASS 的那套侧栏+浅灰底；Wiki/设置/工时不得另起一套挤法。

7. **PRO_ADMIN**：设置页 / 超管台有序密度专册见 [`PRO_ADMIN_VISUAL_BASELINE.md`](./PRO_ADMIN_VISUAL_BASELINE.md)（本波 A/F **专册优先**）。

## 审图检查清单（每张截图）

- [ ] 文字是否挤、糊、截断？
- [ ] 侧栏是否通栏到底？
- [ ] 主区是否只有死白、内容贴顶漂浮？
- [ ] 属性/芯片/表格是否像 2015 后台？
- [ ] 中文角色名是否人话（管理员/机器人，不是 admin）？

## 参考（外部）

- 东亚界面常比欧美更密，但密要**有序**（UX Matters / Chinese UX 实践）
- 中文标题勿为留白压成窄列碎语义（SongStyle：硬约束 > 留白）
- 钉钉等：容器宽度要够，避免省略/重叠/拥挤
