# 建队自动组班（AUTO_CREW）

> 2026-10-24 23:23 Asia/Shanghai · 产品体验  
> **用户定调（总指挥转·P0 怒）：** 团队不会自动组建。现状：建队出空席后还要 **人手逐席** 绑 / 等 Bot 自进。要傻瓜：**建队（或模板）后一键/自动把班底席位就绪**——可预发 **入场链接包** / 模板角色 **一键邀请**；**禁人肉逐席**。  
> **承接：** [`SEAT_VISIBILITY`](./NEXT_WAVE_DEBT_SEAT_VISIBILITY.md)（空席已可见）+ [`ONE_TAP`](./NEXT_WAVE_DEBT_ONE_TAP_JOIN.md) / [`FOOLPROOF`](./NEXT_WAVE_DEBT_ONE_TAP_FOOLPROOF.md)（单席复制 / 露 ymk_）。本包只解决 **整班一次带走**，不重做 join/redeem。

## 一句话

从模板建队成功（或席页对当前队）→ **一个主按钮**「一键就绪班底 / 复制全班入场包」→ 剪贴板（或挡层）里是 **N 席各自带 role 的入场链接+提示词**；Admin **不必**再点 5 次席卡。

## 产品冻结（P0 / 非 P0）

| 层 | 做什么 | 不做（本波） |
| --- | --- | --- |
| **P0 入场包** | 对每个 **空席** 签发带 `role` 的 `ymt_`，打成 **一份** Markdown/纯文本包（每席：席名 + 入场链接 + 入场提示词）；一键复制；建队成功可 **自动弹出** 该包 | 人肉逐席点「复制入场…」 |
| **P0 入口** | ① 建队成功挡层/页顶主 CTA；② 席位页（有空席时）常驻「复制全班入场包」 | 藏进次级菜单 |
| **P0.5 可选** | 若工作区已有 **未入座** Bot，提供「按空席顺序一键指派」或按显示名/slug 弱匹配；一次绑完空席 | 强迫必须先有闲 Bot |
| **P1 后置** | 建队时自动 mint N 个 Bot 成员 + `ymk_`（FOOLPROOF 挡层逐把或打包） | **P0 不做**自动造人；身份钥匙仍走设置/FOOLPROOF |

**「就绪」P0 定义：** 每个空席都有一份 **可立刻发给对应 Agent** 的入场材料（链接或提示词，含安装段 + `ymt_` + role），Admin 一次复制拿走。  
**不要求 P0：** 席卡上已显示演员名（那是 Bot 真 join/指派之后；V7 已覆盖绑后翻卡）。

## 含 / 不含

| 做 | 不做 |
| --- | --- |
| 批量签发：每空席一个 `ymt_`（role=席 slug） | 合并成「一码进全队」改契约（仍一席一码，只是一次复制） |
| 打包文案：分节 `## 前端` / `## QA` …；每节含 ONE_TAP 入场提示词（只 ymt_，**禁嵌 ymk_**） | 把 ymk_ 打进公开入场包 |
| 建队成功后主路径引导复制全班包（可与 SEAT 切队同帧） | 只 Toast「5 空席」就完事 |
| 失败人话：某席签发失败标明席名，其余仍可复制 | 静默部分失败 |

## 契约（行为）

### 入场包内容（每席一节）

```
# 班底入场包 · {团队名}
（含 N 个入场码，勿发公开群）

## {席显示名}（{slug}）
入场链接：https://bot.api.sn.cn/join?code=ymt_…&role={slug}
（下附与 ONE_TAP 同构的入场提示词：安装 + API 根 + ymt_ + role + join 航线；禁 ymk_）
```

### API

- **优先不动 Go：** FE 对空席循环已有 `POST …/teams/{id}/invites`（带 role_hint/slug）。  
- **若**循环体验差（慢/限流/无事务）→ Go 补 `POST …/teams/{id}/invites/batch`：`{ seats: [{ role_slug }] }` → `{ invites: [{ role_slug, code }] }` 明文仅一次。产品验收认「一次动作出全包」。
